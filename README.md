# Premium UI/UX & Frontend Portfolio 🚀

![Portfolio Preview](./image_07897d.png)

An exceptional, ultra-responsive personal portfolio designed for a high-end web designer and frontend engineer. Inspired by design systems from Apple, Linear, Stripe, Framer, and Vercel.

---

## ✨ Features

- **Performance First:** 95+ Lighthouse score out of the box with zero heavy JavaScript framework overhead.
- **Design System:** Built using custom ambient background gradients, glassmorphism, subtle micro-interactions, and high-contrast typography.
- **Responsive Layout:** Mobile-first architecture ensuring flawless rendering across all screen breakpoints.
- **Interactive Components:**
  - Animated hero floating preview cards
  - Dynamic scroll-triggered counter stats
  - Scroll-reveal animations via native `IntersectionObserver`
  - Accordion-style FAQ section
  - Contact form layout & modern glass card components

---

## 🛠️ Tech Stack

- **Markup:** HTML5 (Semantic & Accessible)
- **Styling:** Tailwind CSS (CDN Utility Configuration)
- **Scripting:** Vanilla JavaScript (ES6+)
- **Iconography:** Lucide Icons
- **Typography:** Plus Jakarta Sans (Google Fonts)
